# SPORTLY

Мобильное приложение спортивного магазина на **Python и Kivy**: каталог с фильтрами, корзина, оформление заказа,
учётные записи, админ-панель и обработка сетевых ошибок. Работает на Android и на компьютере в окне размером с телефон.

> Учебный проект, интерфейс сделан по мотивам мобильных приложений спортивных магазинов. Название, логотип и баннеры
> вымышленные, проект не связан с реальными компаниями. Оплата ненастоящая: деньги не списываются, данные карты
> никуда не отправляются.

Автор: [Artemproid](https://github.com/Artemproid)

## Возможности

**Покупки**
- Главная с баннерами, брендами, подборками и шапкой, которая закрепляется при прокрутке.
- Каталог из 136 товаров и поиск с подсказками и историей запросов.
- Фильтры по цене, виду, полу, размеру, бренду, цвету, сезону и другим параметрам. Кнопка показывает точное число товаров.
- Карточка товара с галереей, таблицей размеров, избранным и сравнением.
- Корзина с промокодами и бонусами.
- Оформление заказа: самовывоз с картой пунктов или доставка, статусы заказа и тестовая оплата.

**Пользователи**
- Регистрация и вход по почте или телефону, смена данных и пароля.
- У каждого пользователя свои корзина, избранное, бонусы, адреса и заказы. Данные сохраняются между запусками.

**Админ-панель**
- Сводка по товарам, пользователям, заказам и выручке.
- Товары: цена, скидка, скрытие, добавление новых.
- Заказы: смена статуса и отмена.
- Пользователи: роль, блокировка, бонусы, новый пароль, удаление.
- Режимы сети для проверки экранов ошибок.

**Сетевые ошибки**
- Приложение проверяет настоящее подключение и показывает полосу, когда интернета нет.
- Экраны загрузки предлагают повторить запрос, а вход, оформление и оплата показывают окно с ошибкой.

## Запуск на компьютере

Нужен Python 3.12 (проект проверялся на Ubuntu).

```bash
git clone https://github.com/Artemproid/Sportmaster.git
cd Sportmaster
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
./run.sh
```

Esc работает как кнопка «Назад». Если `python3 -m venv` сообщает об отсутствии `ensurepip`, установите пакет
`python3.12-venv`.

## Демо-доступ

Записи создаются при первом запуске. Они только для локальной демонстрации, пароли можно сменить в разделе «Мои данные».

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin@sportly.local` | `admin12345` |
| Покупатель | `user@sportly.local` | `user12345` |

Админ-панель находится в разделе «Профиль». Тестовые карты:

| Номер | Результат |
|---|---|
| `4242 4242 4242 4242` | Успешная оплата |
| `4000 0000 0000 0002` | Банк отклоняет платёж |

## Сборка для Android

Понадобятся JDK 17, Android SDK и системные пакеты для сборки. Минимальная версия Android: 7.0 (API 24).

```bash
sudo apt install -y openjdk-17-jdk autoconf libtool pkg-config zlib1g-dev libffi-dev libssl-dev
.venv/bin/pip install buildozer==1.6.0 cython==0.29.37

export VIRTUAL_ENV="$PWD/.venv" PATH="$PWD/.venv/bin:$PATH"
buildozer android debug
```

APK появится в папке `bin/` и подойдёт для эмуляторов x86_64 и телефонов arm64. Первая сборка скачивает Android SDK и NDK
и занимает заметное время.

Запуск на эмуляторе (Android SDK в `~/Android/Sdk`, созданный эмулятор `Pixel_10_Pro_XL`):

```bash
./run_emulator.sh            # запустить эмулятор, установить и открыть приложение
./run_emulator.sh --build    # сначала пересобрать APK
AVD=Medium_Phone ./run_emulator.sh    # другой эмулятор
```

Полезные команды `adb`:

```bash
adb shell pm clear org.study.sportly                  # стереть данные приложения
adb shell cmd connectivity airplane-mode enable       # выключить сеть (disable — включить)
```

## Хранение данных

Сервера пока нет. Данные лежат в файле `sportly_db.json` в личной папке приложения, а пароли хранятся как соль и хеш
PBKDF2. Роли и админ-панель проверяются только на устройстве, поэтому в таком виде проект подходит для демонстрации,
но не для настоящего магазина.

Все загрузки уже идут через `app/net.py`, поэтому позже его можно будет подключить к настоящему API.

## Структура проекта

```
main.py              запуск, навигация, нижнее меню, заставка
app/
  catalog_db.py      товары, поиск, фильтры, сортировка
  data.py            разделы, баннеры, пункты самовывоза
  db.py              локальная база, пользователи, роли
  net.py             проверка сети и ошибки запросов
  store.py           корзина, избранное, заказы и бонусы текущего пользователя
  common.py          общие элементы экранов
  widgets.py         кнопки, карточка товара, шторки, анимации
  screens/           экраны приложения
assets/              шрифты, иконки, изображения
tools/               автотесты и подготовка изображений
run.sh               запуск на компьютере
run_emulator.sh      запуск на эмуляторе
buildozer.spec       настройки сборки APK
```

## Тесты

Автотесты запускают приложение и проходят его сценарии, поэтому нужен графический сеанс:

```bash
.venv/bin/python tools/test_flows.py       # каталог, фильтры, поиск, сортировка
.venv/bin/python tools/test_accounts.py    # пользователи, админ-панель, сетевые ошибки
.venv/bin/python tools/shots.py            # прогон покупки со снимками экранов
```
